# Tutorial sound screenshots

These PNGs accompany [Making sounds with DISSCO and LASSIE](../../tutorial_sound.md).

- Source: official DISSCO `main` base, commit [`1fb85dd3a1898339938c1b2ba1b1528e4b0f9f17`](https://github.com/cmp-illinois/DISSCO/commit/1fb85dd3a1898339938c1b2ba1b1528e4b0f9f17), synchronized September 9, 2026, plus the accompanying [sound-editing fixes](https://github.com/DiyunZ/dissco/commit/7f505f39d583f19a9929f462939165c1ecabbd5e) for 24-bit project defaults, envelope editing, and compact function results. Use a build containing that commit when following this tutorial.
- Capture: the freshly built LASSIE Qt widgets, rendered offscreen using Fusion appearance and English labels. A temporary capture entry point linked the same application objects as the fixed build. The images were refreshed after those fixes; no UI elements were drawn over the captures. Images 01, 03, 05, 09, 14, 15, 16, and 42 were updated on September 10. Image 01 names first_tone; 03 and 05 show unconnected setup stages; 09, 15, and 16 show the fixed centered tone without reverb; 14 shows its successful Run; 42 follows the duplicate-envelope exercise.
- Resolution: native 2× rendering into lossless PNG, 1920–3080 pixels wide. Small dialogs have shorter image heights. No image was enlarged from a lower-resolution screenshot.
- Content: the tutorial's project data, function forms, libraries, and modifier dialogs. The process-output image records an actual successful CMOD run.
- Validation: 42 image references resolve; every PNG decodes; all images were checked with English/Chinese OCR, with no Chinese characters detected. Visible labels and parameter layouts were also reviewed. Image 42 shows duplicate Envelope 3 at X = 0.2, Y = 2.5 after saving and reopening. Editing it leaves Envelope 1 unchanged; both supplied projects retain their Y = 1 amplitude peak.

`manifest.json` records each image's pixel dimensions and SHA-256 hash, plus the base/fix commits and widget-source hashes. Captures were made before committing; those source hashes match the linked fix commit. Machine-specific directory prefixes are omitted from manifest window titles. Operating-system window decorations are outside the widget captures, so the appearance can differ from a native macOS, Windows, or Linux desktop window.
